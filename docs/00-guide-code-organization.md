## Step 1: Download and Login to GitHub Desktop

Download **GitHub Desktop** for Windows from the [official website](https://desktop.github.com/) and sign in with your GitHub account. On Ubuntu, follow this [installation guide](https://linuxcapable.com/how-to-install-github-desktop-on-ubuntu-linux/).

<p align="center">
  <img width="900" alt="Download GitHub Desktop" src="../resources/images/tutorial/codestructure/download-github.png" />
</p>

---

## Step 2: Clone Your Repository

Clone the repository to create a local copy that you can edit on your computer.

**2.1.** In GitHub Desktop, choose **Clone a repository from the Internet**.

<p align="center">
  <img width="900" alt="Clone repository option" src="../resources/images/tutorial/codestructure/clone-repo.png" />
</p>

**2.2.** Select the repository you want to clone, choose a local path, then click **Clone**.

<p align="center">
  <img width="900" alt="Clone confirmation dialog" src="../resources/images/tutorial/codestructure/clone.png" />
</p>

---

## Step 3: Organize Your Code

### Fetch and Pull

**Fetch:** Check for changes on GitHub **without** modifying your local files.

<p align="center">
  <img width="900" alt="Fetch from remote" src="../resources/images/tutorial/codestructure/fetch-repo.png" />
</p>

**Pull:** Download changes from GitHub and **merge** them into your current branch.

<p align="center">
  <img width="900" alt="Pull changes" src="../resources/images/tutorial/codestructure/pull-repo.png" />
</p>

---

### Create and Move Files

**3.1.** Open the repository folder in File Explorer using the **Show in Explorer** option.

<p align="center">
  <img width="900" alt="Show repository in Explorer" src="../resources/images/tutorial/codestructure/show-in-explorer.png" />
</p>

**3.2.** Create a new folder to organize your code by topic or category.

<p align="center">
  <img width="900" alt="Create a new folder" src="../resources/images/tutorial/codestructure/create-new-folder.png" />
</p>

**3.3.** Cut the code files you want to move.

<p align="center">
  <img width="900" alt="Cut code files" src="../resources/images/tutorial/codestructure/cut.png" />
</p>

**3.4.** Paste them into the new folder.

<p align="center">
  <img width="900" alt="Paste files into new folder" src="../resources/images/tutorial/codestructure/paste.png" />
</p>

---

### Commit and Push

**3.5.** Back in GitHub Desktop, enter a **Commit Message** describing your changes, then click **Commit to main**.

> **Note:** A commit message is required. For example: `"update leetcode"`.

<p align="center">
  <img width="900" alt="Enter commit message" src="../resources/images/tutorial/codestructure/commit-message.png" />
</p>

**3.6.** Click **Push origin** to send your local commits to the remote repository on GitHub.

<p align="center">
  <img width="900" alt="Push commits to GitHub" src="../resources/images/tutorial/codestructure/push.png" />
</p>

---

### Verify on GitHub

**3.7.** Press **F5** to refresh your GitHub page. The new folder should now appear in your repository.

<p align="center">
  <img width="900" alt="New folder visible on GitHub" src="../resources/images/tutorial/codestructure/new-folder.png" />
</p>
